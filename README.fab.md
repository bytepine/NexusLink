## Title

NexusMCP — Unreal Engine MCP (NexusLink)

## Short description

Connect AI clients to Unreal Engine. Inspect projects, edit Blueprints and materials, and debug PIE with the free, open-source NexusLink MCP plugin.

## Description — English

**Bring your Unreal Engine project into your AI workflow.** NexusMCP is the Fab listing for **NexusLink**, a free, open-source Unreal Engine plugin that connects MCP-compatible AI clients to the editor through the Model Context Protocol.

- **Understand your project:** search assets, inspect properties, query logs, and capture viewport or widget screenshots.
- **Work with editor assets:** read and modify Blueprints, materials, animation, DataTables, UMG widgets, and other supported asset types.
- **Debug in Play In Editor (PIE):** inspect Actors, animation state, behavior-tree blackboards, and optional Gameplay Ability System data.
- **Connect your preferred AI client:** use NexusDesktop, the Nexus MCP integration for VS Code / Cursor, or the Nexus MCP integration for JetBrains Rider to discover UE instances and configure the connection.

Install the UE plugin, enable it, and turn on **Editor Preferences → Plugins → NexusLink → Enable MCP Server**. Choose one desktop or IDE integration and follow the setup guide to connect your AI client.

Capabilities depend on the installed package version, engine version, and enabled engine plugins. Optional Lua workflows require UnLua; consult the setup guide for extension requirements for your version.

## Description — 简体中文

**让 AI 直接了解你的 Unreal Engine 项目。** NexusMCP 是 **NexusLink** 在 Fab 上的商品名称。这个免费开源的 Unreal Engine 插件通过 Model Context Protocol（MCP），将兼容的 AI 客户端连接到编辑器。

- **了解项目**：搜索资产、检查属性、查询日志，并获取视口或控件截图。
- **处理编辑器资产**：读取和修改蓝图、材质、动画、DataTable、UMG 控件等受支持的资产。
- **调试 PIE**：检查 Actor、动画状态、行为树 Blackboard 和可选的 Gameplay Ability System 数据。
- **连接 AI 客户端**：通过 NexusDesktop、VS Code / Cursor 的 Nexus MCP 扩展，或 JetBrains Rider 的 Nexus MCP 插件发现 UE 实例并生成连接配置。

安装并启用 UE 插件，在 **Editor Preferences → Plugins → NexusLink** 勾选 **启用 MCP 服务器**。任选一个桌面或 IDE 客户端，按安装指南连接 AI。

具体能力取决于已安装包的版本、引擎版本和启用的引擎插件。可选 Lua 工作流依赖 UnLua；对应版本是否需要扩展插件请参阅安装指南。
