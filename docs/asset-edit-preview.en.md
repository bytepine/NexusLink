# Asset edit preview
[中文](asset-edit-preview.md) · English

[Documentation](README.en.md) · [Home](../README.en.md)

For initial node/link and widget-tree structure plans, StructureHash preconditions, and bVerifyStructure readback, see [feature additions](feature-followups.en.md#结构预览与回读). This guide covers property value preview and verification.

GetAssetEditPreview parses values in temporary property storage, returning PropertyType, CurrentValue, normalized TargetValue, bValid, and per-item Error. It does not write real properties, compile, save, or record Undo. Requests include one AssetPath, target Capability, and Operations retaining existing write-operation formats:

```json
{
  "AssetPath": "/Game/YOUR_TABLE",
  "Capability": "ManageAssetDataTable",
  "Operations": [{"Action": "Set", "RowName": "YOUR_ROW", "FieldName": "YOUR_FIELD", "Value": "12"}]
}
```

Confirm paths, row names, and field names with read tools first. Supported operations include ManageAssetBlueprint/SetDefaults, ManageAssetDataTable/Set, ManageAssetUserWidget/SetProperty, and the operations listed below. Leaf types include bool, numbers, enums, strings, Name, Text, type-checked object/class references including None, complete structs, arrays, Set, and Map. References themselves can be assigned; traversal through references is restricted to target-owned subobjects. Null/external-object traversal, fixed arrays, and paths through containers are rejected. Whole values containing instanced object references return Verification=Unsupported; use owned-subobject leaf paths. Blueprints must already have usable generated classes and CDOs; preview does not compile or create missing CDOs. Every preview reads real current values, without simulating earlier preview writes.

For writing, supply ExpectedValue in the operation, preferably preview CurrentValue, and top-level bVerify=true. ExpectedValue is normalized/computed in the same type; empty string is a valid previous value. A mismatched previous value prevents writing.

```json
{
  "AssetPath": "/Game/YOUR_TABLE",
  "bVerify": true,
  "bSaveToDisk": true,
  "Operations": [{"Action": "Set", "RowName": "YOUR_ROW", "FieldName": "YOUR_FIELD", "Value": "12", "ExpectedValue": "7"}]
}
```

bVerify is off by default. When enabled it verifies the corresponding reflection-property operations above and Blueprint SetArray/ClearArray. Level/Blueprint-component batches may mix ResetActorPropertyToDefault / ResetComponentPropertyToDefault, including arrays. Resets reject ExpectedValue and restore/compare complete reflected values, including zero-valued fields omitted by text export. Other unsupported operations reject the entire call before any write. Blueprint SetDefaults checks the previous value, records Undo, writes, and immediately reads back. After the batch, bCompile=true compiles once, relocates final properties, verifies them again, then saves according to bSaveToDisk if verification succeeded. Default bCompile=false verifies memory only; neither ExpectedValue nor bVerify triggers a full Blueprint compile. Repeated writes to one property verify the final write at completion; earlier entries retain immediate readback. WBP SetProperty verification still compiles and reads back. Results include OldValue, NewValue, ReadbackValue, bWritten, bVerified, Verification, VerificationSupport. Unsupported property types explicitly report Unsupported; compile, readback mismatch, and save errors are separate. Without requested verification, Verification=NotRequested.

A single Manage call preserves partial success: earlier successful edits remain. Any verification failure prevents automatic saving; do not claim the asset was restored. Cross-call CallCapability.Calls batches retain transaction rollback; saving follows memory transaction completion. Save failure does not imply whole-disk rollback. Failed writes are not automatically retried.


ManageAssetBlueprint/RenameVariable uses VariableName/NewVariableName and native engine member rename, retaining variable GUIDs/references. Only leaf Blueprints without child Blueprints are allowed. Active asset-registry scans, registered/loaded children, RepNotify members, inherited members, or name conflicts reject before writing. Some native engine renames reset subclass defaults; this interface therefore does not offer safe renaming with children. VariableType supports primitives, object classes, ClassReference<BaseClass>, BlueprintType struct names/paths, T[], Array<T>, Set<T>, Map<K,V>. Nested containers are unsupported; Set elements/Map keys must be hashable.

GetAssetBlueprint Component uses native components in the target CDO and SCS inherited override templates for the target generated class. TemplatePath identifies the value source; bOverridesResolved=false means unresolved target overrides fell back to ancestor templates.

For level properties, use GetAssetLevel ActorProperties: discover exact ActorName from Actors, then supply 1–32 PropertyPaths to obtain Value, DefaultValue, bDiffersFromDefault. Defaults come from Actor-class CDOs, matching ResetActorPropertyToDefault. Reads/previews/writes are restricted to the actual ULevel matching AssetPath, including loaded streaming sublevels, and do not edit across packages through the main-level path. ActorPath/LevelPath are returned. If Actor values exist but default subobjects do not, bDefaultUnavailable/DefaultError are returned without failing the whole read. Full-level export is unnecessary. ExportAsset selects an exporter by extension and runs automated; large-asset export duration is not guaranteed.

Reparent ordinary, Widget, Anim, and native GameplayAbility Blueprints through ManageAssetBlueprint Operations=[{"Action":"Reparent","ParentClass":"Character"}], or a Blueprint asset/full generated-class path. Preview the same operation with GetAssetEditPreview for compatibility, member conflicts, affected inherited properties, and children; preview is not compile proof. Undo is retained; full compilation/saving are controlled independently by top-level bCompile/bSaveToDisk without implicit full compilation. Leaving the current ancestor chain requires per-operation bAllowPotentialDataLoss=true and may lose defaults or invalidate references. Rejects PIE, inheritance cycles, specialized-type mismatches, crossing Actor/ActorComponent/plain-object families, incompatible specialized bases/skeletons, member conflicts, and interfaces redeclared by the new parent.

Read-only navigation uses GetNavigationPath with Start={X,Y,Z}, End={X,Y,Z}, World=Auto|Editor|Play; Auto prefers PIE/Game. Optional ActorName supplies an ordinary Actor as agent context without AIController. It never moves Actors or creates/rebuilds navigation. Missing navigation returns bNavigationAvailable=false, QueryResult=Unavailable; unreachable targets bPathFound=false. Partial paths require bAllowPartialPath=true. MaxPoints (1–2048, default 256) limits returned points only; Length/Cost/PointCount describe the full path and bTruncated flags truncation.

ControlEditorAssetEditor(AssetPath=…, Action=Open) opens/focuses asset editors. Focus only focuses existing editors; Status queries; Close only closes saved editors not sharing an instance with other assets. Explicitly SaveAsset first when dirty: nothing implicitly saves or discards changes. GetEditorContext(Sections=["AssetEditors"]) returns assets, editor names, dirty state. bValidateOnly=true leaves UI unchanged. Open/Focus/Close require renderable GUI Editor; headless supports Status and validation-only. Returns bWasOpen, bIsOpen, bDirty, bCanClose. Atomic multi-call batches are forbidden. Use ControlEditorLevel for maps.


Variable-type readback also provides ContainerType, CanonicalType, ElementType, Map KeyType/ValueType, full type-object paths, and Guid. Function lists include local-variable types/GUIDs. RenameLocalVariable uses FunctionName, VariableName, NewVariableName. Member/local rename and ChangeVariableType protect child Blueprints and wait for asset-registry scanning. Type changes also reject implicit RepNotify or Set/Map replication changes. Preview ChangeVariableType, then explicitly bAllowPotentialDataLoss=true. It retains GUIDs, clears old defaults, rebuilds references in this Blueprint, and does not guarantee old links/external dependencies still compile.

Property preview/post-write verification support ManageAssetDataAsset/Set (PropertyName), ManageAssetLevel/SetActorProperty (exact ActorName/PropertyPath), ManageAssetBlueprint/SetComponentProperty (ComponentName/PropertyPath). ExpectedValue protects against stale writes. Reflection leaves, complete structs/containers, and owned-subobject paths are supported; external-object traversal is rejected. Scientific notation such as 1e3 is consistently accepted in regular writes, preview, previous-value checks, and verification; invalid/nonfinite values never write. Ordinary level-property writes consistently support dotted paths, empty strings, and prewrite parse rejection.

## Batch Blueprint migration

- GetAssetBlueprint(Sections=["Defaults"], PropertyPaths=["Mesh.SkeletalMesh","Mesh.RelativeRotation"]) reads precise nested defaults. Each requested path returns a value or error; MissingPropertyPaths lists missing entries.
- AddNode K2Node_CustomEvent uses CustomEventName; SetNode renames through the same field. Conflicts reject before edits and return final names. FunctionName on a custom event explicitly errors.
- Reparent preflight returns bounded AffectedGraphReferences for variables, event overrides, and parent calls. Manage bRequiresCompile and GeneratedClassState=Missing|Stale|CompileError|Current describe generated-class state; bChanged=true does not imply compilation. Write new-parent fields after explicit compilation.
- RemapMemberReferences uses OldMemberName/NewMemberName and migrates only inherited self-property getters/setters in this Blueprint. Destination must be Blueprint-visible on the current parent; value-pin types must match exactly, and setters require writable properties. Member references/value-pin names change while pin GUIDs/defaults/links remain. Use bValidateOnly=true or GetAssetEditPreview first. Functions/events and external-object references are outside scope.
- SetArray takes typed JSON Values; [] clears. Numeric elements/nested numeric fields require finite JSON numbers; integers cannot have fractions or exceed property/native-converter ranges. Invalid arrays reject before any element write. ClearArray needs no Value. Both use PropertyPath, with optional ComponentName for templates. Generic string Value retains Unreal import-text: containers need parentheses or empty string. In UE4 empty string clears arrays, while () may create one default element; unspecified struct fields retain values. Mixed property/array/reset batches may share bVerify=true.
- GetAssetLevel(Sections=["ActorPropertySchema"]) requires exact ActorName. PropertyPaths optionally selects struct/owned-subobject roots; otherwise starts at the Actor. SchemaDepth=0..3 and MaxSchemaProperties=1..256 bound recursion and total fields. Returns names, types, editability, children, truncation. External objects are not followed; nonempty instances remain discoverable when CDO values are null.

SaveAsset, CompileBlueprint(bSaveToDisk=true), and manage automatic saving check UFunction super chains before SavePackage. Temporary objects, replaced classes, and cycles return SaveDiagnostics with ErrorKind=InvalidSuperFunction, FunctionPath, SuperFunctionPath, Reason, without saving or clearing dirty state. Successful compilation and safe saving are separate results. The check does not change third-party runtime function bindings.

For component queries use GetAssetBlueprint(Sections=["Component"]) with ComponentName, at most 32 PropertyPaths, and Baseline=ClassDefault|ParentTemplate, returning Value, DefaultValue, bDiffersFromDefault, BaselinePath. Without paths, bounded editable fields are listed. Existing component summaries retain component-class CDO baselines; explicit ParentTemplate compares the actual target-parent template. ResetComponentPropertyToDefault uses the same baseline, default ParentTemplate; owned components without parent templates require explicit ClassDefault. Resets are restricted to components/owned subobjects, with actual property Owners in the matching component scope. Changes are recorded on actual Owners; ordinary inherited writes/resets support Undo. Copying parent templates to restore instanced subobject/component references is rejected.

Centralized compilation and CompileBlueprint return CompilerErrorCount, CompilerWarningCount, up to 128 CompilerMessages with severity/message and resolvable GraphName/NodeId, plus truncation. All compile/save helper paths avoid saving on failure; disk rollback is outside memory Undo transactions.

Project navigation points with GetNavigationPoint(Point={X,Y,Z}). Paths accept bProjectStart/bProjectEnd, ProjectionExtent (default 100/100/250, nonnegative axes), FilterClass, positive AgentRadius/AgentHeight, and WorldName for exact World selection. Results report navigation system/data presence and build status; projection failures are explicit, never rebuilding automatically. InteractRuntimeActorAI MoveTo accepts the same filter, destination projection, partial-path policy, AcceptanceRadius; Stop stops movement. GetRuntimeActorAI reports current movement and this tool's latest captured request result, including request ID, completion, and Success/Blocked/OffPath/Aborted, or Unknown without captures. Acceptance does not mean arrival; captures are process-local.

GetAssetExportOptions discovers registered exporters/formats and can check primary output existence. ExportAsset/bValidateOnly=true creates neither directories nor files. ConflictPolicy=Fail|Unique|Replace applies to the primary output, default Replace preserving existing behavior. Exporters may write sidecar files depending on format/options; format discovery does not promise every configuration exports successfully.

Before navigation writes read GetEditorContext(Sections=["CurrentMap"]). Levels includes loaded AssetPath, current/selected/locked/visible/bDirty flags, scene BoundsMin/BoundsMax, and navigation volumes. Call ManageAssetLevel for the selected level with Action=CreateNavMeshBoundsVolume and world-space BoundsMin={X,Y,Z}/BoundsMax={X,Y,Z}. Native Actor Factory/CubeBuilder create actual geometry at unit scale. ResizeNavMeshBoundsVolume takes exact ActorName and the same bounds, rebuilds existing geometry, refreshes navigation bounds, returns actual bounds, and preserves Undo without implicit compilation/building. Save the volume's level, then ControlEditorScene(Action=BuildNavigation), querying OperationId through GetEditorOperation. Submission returns a task ID first; native building may delay editor responses. Wait rather than resubmitting. Check CompatibilityResult.Outcome, bBuildComplete, bHasNavigationData, then points/paths for walkable areas. bSaveToDisk=true requires all loaded levels saved before building; rejection includes DirtyLevelPaths. Completion saves generated level packages. Saving is package-wide, including edits made during the build.

Legacy Skeleton retargeting uses ManageAssetAnimSequence or ManageAssetAnimBlueprint with Action=Retarget, TargetSkeleton=.... First bValidateOnly=true checks MissingBones, UnmappedAnimations, AffectedAssets without top-level bCompile/bSaveToDisk. Writes require bAllowPotentialDataLoss=true. DuplicateAsset first to retain sources. ABP uses explicit AnimationRemaps=[{SourceAssetPath,TargetAssetPath}]; destinations must already use the target Skeleton and matching types. Retarget parent ABPs first; the current ABP must have no children. Sequence bConvertSpaces controls reference-pose space conversion. Referenced animations require bRetargetReferredAssets=true. AdditionalDirtyAssets lists native side effects, saved together by bSaveToDisk. ABP compilation follows top-level bCompile. This is legacy Skeleton retargeting; UE5 IK Retargeter uses separate capabilities.

AddVariable supplies DefaultValue when the engine creates the variable. After full compilation, only newly added fields still at type-initial values are populated in loaded subclass CDOs/instances; existing fields and nondefault overrides remain. NewVariableDefaultPropagations/NewVariableDefaultPackages report affected items; child Blueprint/level packages still need explicit saving. Existing broken assets are not automatically reset, avoiding overwriting project configuration.
