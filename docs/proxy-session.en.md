# Proxy session contract
[中文](proxy-session.md) · English

Results containing standard MCP content[] image blocks pass through unchanged, preserving PNG/JPEG MIME types, base64, and existing text/structuredContent metadata. All three clients skip text offloading and proxy caching when type=image is present; asynchronous and batch calls use the same rules. UE attaches only trusted files generated by screenshots: at most 4 images and 4 MiB total raw image bytes per response, retaining paths and explanations when omitted. Proxies do not decode/convert images again or read UE file paths.

[Documentation](README.en.md) · [Home](../README.en.md)

Desktop / Rider / VSCode sit between the AI client and UE WebSocket. This document defines protocol additions that all three must align on; gameplay semantics remain in NexusLink.

Reference implementation: nexus-vscode/src/proxy/. Rider / Desktop use matching fields and decisions.

---

<a id="1-职责边界"></a>
## 1. Responsibility boundaries

| Layer | Does | Does not |
|---|---|---|
| **Proxy** | TTL/section caching, disconnected snapshots, pre-write confirmation, Pause queuing, cockpit activity, large payload offloading | Capability semantics, SearchCapabilities, UE schema changes |
| **UE** | Inject SnapshotAt / TtlSeconds where implemented; confirm dangerous capabilities (dangerous tag) in Confirm mode | Trim Agent history |

Direct connections to :45000 have **none** of this layer. Agents must work without _proxy.

---

<a id="2-_proxy-对象"></a>
## 2. The _proxy object

The proxy injects this into the MCP Result of tools/call, preferably at top-level _proxy in JSON parsed from content[0].text; parsing failure uses result._proxy:

| Field | Type | When present |
|------|------|----------|
| cache | "hit" \| "section_hit" | Session cache used without forwarding to UE |
| degraded | "unavailable" | UE unreachable; returning the last read snapshot |
| snapshotAt | ISO-8601 UTC | Snapshot timestamp, preferring UE SnapshotAt |
| offloaded | true | Body saved to a local file |
| path | string | Absolute path saved on disk |
| bytes | number | Number of bytes saved |
| note | string | Short Agent hint in fixed English; avoids changing initialize and breaking Prompt Cache. This hint is in the call result. |

When degraded, **do not** loop list_unreal_instances. Example Note:

`UE editor unreachable (compile/restart?). Serving last snapshot. Do not loop list_unreal_instances.`

Disconnected writes retain the existing JSON-RPC `error.data.errorKind: "proxy_not_connected"` without a degraded snapshot; section 4 defines additional fields for uncertain execution outcomes.

<a id="3-ttl-缓存键"></a>
## 3. TTL cache keys

All three clients use the current PascalCase contract: CallCapability / Capability / Arguments / Calls, Operations[].Action, Sections, and response SnapshotAt / TtlSeconds. MCP envelopes and top-level proxy routing targetHost / targetPort keep their existing spelling.

**Instance scope:** isolate cache entries by the final UE host/port. Explicit targets share the scope when they address the current persistent connection. Normalize localhost / ::1 to 127.0.0.1; target ports must be integers 1024–65535. For an explicitly invalid targetPort, all three clients return JSON-RPC -32602 before cache lookup, Pause queuing, or confirmation and never fall back to the current instance. Disconnection preserves the last successfully connected scope. Switching instances must not reuse another instance's cache; recompute from the actual target after reconnection. Responses spanning a switch must not pollute the new instance's cache.

For CallCapability: instance scope + Capability + inner Arguments. Only top-level targetHost / targetPort are proxy routing fields; identically named capability arguments remain part of the key.
MultiTool: the tool name is the capability.
Calls[] batches: **not cached**.

**Exact hit:** same capability + normalized JSON arguments, including Sections, and not expired → cache: "hit", without forwarding.

**Section shortcut:** all read parameters except Sections match, including identity, ComponentName, PropertyPaths, filters, Baseline, etc.; cached Sections contain All or a superset of requested Sections, and age is at most **30s** → cache: "section_hit". The old payload may contain more than requested. This aligns with UE's RedundantCall window to avoid another GameThread call.

TTL：

- Use response TtlSeconds when present.
- Otherwise volatile capabilities (GetOutputLog, list_runtime_*, get_runtime_*, CaptureViewport) default to **8s**.
- search_* defaults to **60s**.
- Other get_* / list_* default to **30s**.
- Writes are **not cached**.

Each process keeps at most **64** LRU entries. Successful writes invalidate matching read-cache identities only within the same instance scope.

<a id="4-断线-continuity"></a>
## 4. Disconnection continuity

tools/list retains its existing behavior: the last tool names remain available while disconnected.

For tools/call reads with disconnected WS, return a capability snapshot when available, even if expired, for search_*, get_asset_*, get_editor_*, GetAssetRefs, and GetGameplayTags; mark degraded: "unavailable".

Expired volatile runtime/log snapshots do **not** serve degraded results and return proxy_not_connected.

After reconnection, existing tools/list_changed refreshes the catalog. Read caches remain until write invalidation or LRU eviction.

Ordinary reads may retry once after reconnecting; writes, batches, and editor operations are not automatically resent. A disconnection or timeout after sending a write cannot establish that UE did not execute it. Keep `error.data.errorKind` (`proxy_not_connected` or `proxy_timeout`) and also return `executionStatus: "unknown"` and `retryable: false`. These fields belong to JSON-RPC `error.data`, not the successful `_proxy` result, and do not change UE Capability parameters or error semantics.

An unknown write outcome also invalidates old read caches and disconnected snapshots for the affected instance so pre-write evidence does not conceal a potentially applied change. Query actual asset/runtime state first. When an existing long operation returned an `OperationId`, use `GetEditorOperation` from the owning session while it still has access to obtain its terminal state. Attempt `ControlEditorOperation` cancellation only when `bCanCancel=true`; a cancellation request or client timeout does not mean an engine call rolled back. Preserve the unknown outcome when it cannot be verified instead of automatically writing again. Synchronous capabilities without an `OperationId` do not automatically become asynchronous tasks.

<a id="5-写入前确认与-pause"></a>
## 5. Pre-write confirmation and Pause

The writeGate setting has the same name/semantics in all three clients:

| Value | Behavior |
|----|------|
| off | No confirmation |
| destructive (default) | DeleteAsset / RenameAsset; ControlPie Action stop/end/quit; manage_* with an operations[].action containing delete/remove/destroy |
| all | Every write capability: anything outside Get*/List*/Search*/SubmitFeedback |

Confirmation outcomes: allow / deny / always. Always suppresses further prompts for that capability in the current MCP session; a new initialize prompts again.
deny → JSON-RPC ErrorKind: proxy_denied.
Without a UI callback, as in tests, allow without blocking. Confirmation waits at most **120s**; timeout means deny.

With writeGate: all, exec_* / eval_* / dofile_* also count as writes and prompt in the proxy first. Dangerous code-execution confirmation happens in **UE**, including direct :45000 connections. In Editor Preferences "Confirm each time" access mode, NexusLink prompts and returns ErrorKind=UserDenied on denial. Enabling both layers causes two prompts; leave dangerous-capability confirmation to UE and keep proxy writeGate at destructive.

**Pause:** queue subsequent remote tools/call requests without forwarding to UE. Local list_unreal_instances / connect_unreal_instance remain usable. Resume forwards in arrival order.

<a id="6-驾驶舱"></a>
## 6. Cockpit

The status bar/tray displays the current or most recent remote call: Capability plus a truncated identity. It shows paused status during Pause. This is not written into initialize.instructions.

---

<a id="7-大包保存到磁盘"></a>
## 7. Large payload offloading

When content[0].text exceeds **48000** characters, write it under the system temporary nexus-mcp-offload/ directory and replace result JSON with a summary plus _proxy.offloaded / path / bytes. Agents can open the path with a Read tool.

---

<a id="8-status-与选实例"></a>
## 8. /status and instance selection

UE GET /status adds these fields alongside NetRole:

| Field | Meaning |
|------|------|
| HostKind | Editor / Game / DedicatedServer. Process-level; **does not change with PIE** |
| bHasPlayWorld | Whether a PIE/Game World exists, aligned with list_runtime_* probes |

After PIE starts in the editor, NetRole becomes Standalone/Client/etc. **Do not** use it to identify an Editor process.

All three clients autoconnect by preferring HostKind=Editor, falling back to NetRole=Editor for older UE without HostKind, then found[0]. list_unreal_instances exposes both fields. Do not call list_runtime_* when bHasPlayWorld=false.
