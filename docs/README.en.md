For first use, start with the [quick start](../README.en.md#quick-start). Once MCP is connected, select a guide by task below. Tool names, availability, and parameters are authoritative in the catalog returned by the current connection.

Each guide has complete Chinese and English files, linked at the top of the page.

<a id="日常操作--workflows"></a>
## Workflows

- [Asset edit preview](asset-edit-preview.en.md): preview Blueprint defaults, DataTable fields, and Widget properties; check previous values and verify writes.
- [Runtime UMG interaction](runtime-widgets.en.md): find widgets by instance path and handle ambiguous names, reconstruction, and visibility limits.
- [Editor tools](editor-toolsets.en.md): advanced Slate interaction, UMG structure, standard screenshot images, Automation/Live Coding, PCG/Niagara diagnostics, semantic search, skills, and settings/plugin discovery.
- [MVVM data binding](mvvm-bindings.en.md): contexts/property paths, binding directions, unary conversion functions, and post-compile readback.
- [Dangerous Capabilities and script execution](usage-guide.en.md#210-危险-capability-与脚本执行): access modes, confirmation flow, Python prerequisites, and write risks.
- [Installing the AIRules template](usage-guide.en.md#29-挂载-airules): install rules into a game project and maintain project-specific settings.
